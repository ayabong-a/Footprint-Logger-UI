# Footprint-Logger-UI

A simple web app to track daily activities and estimate CO₂ emissions across **Transport, Food, and Energy** categories. Users can log, edit, and delete activities, filter by category, and view a visual summary of their emissions.

**Live Demo:** [https://aquamarine-valkyrie-bc9181.netlify.app/](https://aquamarine-valkyrie-bc9181.netlify.app/)

## Features

- **Log Activities:** Select category and activity, enter amount, and automatically calculate CO₂.  
- **Edit/Delete:** Update or remove any logged activity.  
- **Filter by Category:** Focus on Transport, Food, or Energy activities.  
- **Visual Summary:** Bar chart showing total emissions by category.  
- **Persistent Data:** Saves activities in `localStorage` across sessions.  
- **Accessibility:** Proper labels, `aria-live` for totals, keyboard focus styles.

## Tech Stack

- HTML, CSS, JavaScript (Vanilla)  
- LocalStorage for data persistence  
- Deployed on Netlify  

## Usage

1. Open the [live app](https://aquamarine-valkyrie-bc9181.netlify.app/).  
2. Add activities by selecting category, activity, and amount.  
3. Filter, edit, or delete activities as needed.  
4. View the bar chart for a summary of emissions.
